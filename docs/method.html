Method

How a cost is computed

Walk the book from the mid, take the fill you would actually get, add the taker fee. Where the displayed book runs out before the position does, the number is a floor and is shown with a >.

The four steps

1. Reference

The mid, not the best bid. Crossing the spread is money the seller actually pays, so charging it to the exit is the honest accounting.

2. Walk

Consume the bid side level by level until the stated notional is filled. The average fill price against the mid is the impact.

3. Fee

A flat 10 bp taker fee is added. It is the published schedule, not a measurement, and it is the only typed number on this site.

4. Floor or estimate

If the displayed book runs out first, the answer is a lower bound, marked, never rounded up into a figure that looks exact.

Every figure here is estimated, never observed. A displayed quote is not a fill: size can be withdrawn, and a real order moves the book it is measured against. The reference is the mid rather than the best bid, because crossing the spread is money the seller actually pays. Where a symbol returns no depth but a live quote, the cost is computed from the top of book alone and everything below it is unknown, not absent.

Slicing is given as a bound, not a number

Splitting an exit into parts helps only if the book refills between them, and how fast it refills cannot be read off a single snapshot. So the desk returns a best case, which assumes full replenishment, and a worst case, which assumes none. The truth is somewhere inside, and the bound is stated rather than a midpoint invented.

Egress

Exit liquidity for tokenized US equities. Egress reads every listed instrument on Bitget every five minutes and measures what it costs to leave a position, at a stated size, from the book that exists.
